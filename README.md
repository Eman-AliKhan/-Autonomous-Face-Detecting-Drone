# 🚁 Autonomous Face Detecting Drone

An embedded systems and computer vision project exploring face detection and drone control using ESP32-CAM and Arduino-based programming.

## 📌 Project Overview

The **Autonomous Face Detecting Drone** project combines embedded programming, camera-based vision, and drone control concepts. It includes code for an ESP32-CAM web server, a face-mask model, and propeller control.

The project explores how camera input and embedded hardware can be used in intelligent drone systems.

## ✨ Key Components

- **ESP32-CAM Web Server:** Camera-related functionality and web server implementation using ESP32-CAM.
- **Face Detection Model:** A model file associated with face-mask detection.
- **Propeller Control:** Arduino code for propeller-related control functionality.
- **Embedded Programming:** Firmware development for microcontroller-based systems.

## 🛠️ Technologies & Tools

- **ESP32-CAM** — Camera-enabled microcontroller platform
- **Arduino / C++** — Embedded programming
- **Computer Vision** — Face-related visual processing
- **Embedded Systems** — Hardware and firmware integration

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the `.ino` files using the Arduino IDE.
3. Install the appropriate ESP32 board support package and required libraries.
4. Configure the board, camera settings, and network credentials as needed.
5. Review the wiring and hardware configuration before uploading firmware.
6. Test camera and motor-control functionality separately before attempting integrated flight.

**Note:** The exact configuration depends on the hardware, libraries, and implementation used in the project.
